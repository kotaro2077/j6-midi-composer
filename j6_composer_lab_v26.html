音色選択

SOUNDを押して音色選択モードに入り、ステップ1～8で音色を選択します。TEMPO/VALUEでも変更できます。

バンク選択

SOUNDを押しながらステップ1～8を押します。8バンク×8音色で、プリセット・パッチは64音色です。

パターン

ユーザー・パターンは64個です。MIDI Program Change 0～63でPattern 1～64を扱います。

エフェクト

内蔵エフェクトはDELAYとREVERBです。

USB

USB Type-C端子はUSB AudioとUSB MIDIに対応します。

MIDI受信

Note On/Off、CC64 Hold、Program Change、Clock、Start、Stopを扱います。公開MIDI仕様では音色つまみ位置の読み出しには対応しません。

パターン Program Change

PC 0–63 → Pattern 1–64

MIDI MONITOR

J-6 USB MIDI セットアップ

1. USB接続

USBハブを避け、データ通信対応ケーブルでJ-6とPCを直接接続します。

2. AIRA LINK

通常のPC接続ではA.LnKをOFFに設定し、設定後にJ-6を再起動します。

3. MIDI Channel

受信チャンネルはAuto DetectでJ-6のNote Onから自動検出します。送信チャンネルはJ-6のSynth Channelに合わせます。

4. ブラウザ

Chrome系ブラウザでMIDIを有効化し、入力・出力の両方にJ-6を選択します。

仕様メモ

演奏MIDI

Note On/Offは0–127。Velocity対応。AftertouchとPitch Bendは非対応です。

Hold

J-6は受信側でCC64 Holdに対応します。

Pattern PC

Program Change 0–63を送受信し、専用チャンネル初期値は16です。

Clock / Transport

MIDI Clock、Start、Stopを送受信します。Continueは非対応です。

音色選択

SOUNDを押し、ステップ1–8で音色、SOUNDを押しながらステップ1–8でバンクを選択します。
